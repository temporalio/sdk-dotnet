# Amazon S3 External Storage Driver Client for the AWS SDK

> [!WARNING]
> This extension is experimental and may change in the future.

This extension provides `AwsSdkS3StorageDriverClient`, an `IS3StorageDriverClient` for
`S3StorageDriver` backed by the official [AWSSDK.S3](https://www.nuget.org/packages/AWSSDK.S3)
package. See `Temporalio.Extensions.ExternalStorage.S3` for usage.
